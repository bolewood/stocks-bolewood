# API routes

- `/api/dxyz-history` — daily DXYZ price/volume history (Yahoo upstream) with a 1-hour cache, stale-cache fallback, and a checked-in snapshot (`app/api/dxyz-history/snapshot.json`) as last resort. Returns `{ rows, source, asOf }` where `source` is `live | cache | stale | snapshot`. Consumed by `components/DXYZNAVFinder.jsx` via `lib/dxyzAtm.mjs`.
- `/api/prices` — real-time quote fetch shared by the NAV/SOTP finders (60s in-memory cache, hardcoded per-ticker fallbacks). Tickers: `ECHO`, `SPCX`, `DXYZ`, `VCX`, `SFTBY`, `ARM`, `9984.T` (as `TOKYO9984`), `USDJPY=X` (as `USDJPY`) — `ECHO` replaced `SATS` after EchoStar's 2026-06-24 Nasdaq ticker change, and the response carries a temporary `prices.SATS` alias for pre-migration client bundles. Returns `{ prices, source, asOf }` where `source` is `live | cache | partial | fallback`. Uses `lib/yahooQuote.mjs` (`fetchChartPrice` / recycled-ticker guard), same v8 chart path as `/api/ai-prices`.
- `/api/ai-prices` — Yahoo v8 chart prices for the Anthropic/OpenAI wrapper table. Price only. Curated share counts, stakes, and marks live in `data/` and load through `lib/loadAiData.mjs`. 60s in-memory cache, per-ticker fallbacks, recycled-ticker `meta.symbol === ticker` guard. Returns `{ prices, quotes, source, fetchedAt, cacheWrittenAt }` where page-level `source` is `live | cached | close | stale | unavailable` (`lib/priceState.mjs`). Parse helpers live in `lib/yahooQuote.mjs`.
- `/api/arkvx-shares` — Class D published SO, used only as a current-assets proxy. ARKVX look-through denominator is NPORT-EX total net assets.
- `/api/investor-day` — Anthropic Investor Day tape payload `{ asOf, source, baselines, perps, polymarket, kalshi, proxies, errors }`. Hyperliquid `io` dex (`io:ANTH`/`io:OAI` ctxs, 5m + 1m (from 23:45 ET) + 30-day 15m candles; `sigmaSeries` `{t, sigma, ret, mark}` is the rolling 15m return at each 1m close ÷ the 30-day 15m σ, `mark` = 1m trade close; `markSigmaEchoes` flags points whose 15m base sits inside an earlier opposite-sign ≥3σ run and that are under 3σ vs that run's pre-spike level; `sigmaSummary` counts non-echo ≥3σ minutes and breach runs (plus `echoMinutes`), and drives the meter's current σ and peak; the meter headlines the move's percentile rank among all available 15m moves — Hyperliquid serves only the latest ~5,000 candles, so the start date rolls forward; `multiDay` is the since-Oct-14 series, memoized 60s), Polymarket Gamma by slug + CLOB history, Kalshi markets + candlesticks (server-side; Kalshi blocks browser CORS), Yahoo 5m charts for proxies vs QQQ. 15s CDN cache; proxy quotes memoized 60s; 00:00 ET baselines memoized 10 min. Math in `lib/investorDay.mjs`.
- `/api/private-tape` — DXYZ Private Tape payload. Fetches Hyperliquid `candleSnapshot` rows for `io:ANTH` and `xyz:SPCX`, DXYZ/QQQ Yahoo candles, then returns cards, correlations, overnight lead/lag samples, residuals, and downloads. Curated assumptions live in `data/private-tape.json`; raw live market prints stay runtime-only. `/api/private-tape/manifest` is the machine-readable open-data contract.

# Pages

- `/sats` permanently redirects (308) to `/echo`, and `/investor-day` (plus `/investor-day/:path*`, for cached share-card URLs) to `/anthropic-ipo-tape` (`next.config.mjs` `redirects()`, covered by `test/redirects.test.mjs`).
- `/dxyz` — Destiny Tech100 NAV calculator (`components/DXYZNAVFinder.jsx`). June 30, 2026 N-CSRS / NPORT-P unit counts via `lib/dxyzHoldings.mjs`, reading the shared DXYZ wrapper record. `lib/dxyzNav.mjs` owns the NAV ledger, August OpenAI estimated units from shared `unitLots`, and $169M cash-funded subsequent purchases. The purchase toggle is independent of ATM; Restore June 30 snapshot disables both and live SPCX. ATM bridge `lib/dxyzAtm.mjs` (same module as `/ai`). Anthropic/OpenAI scenario inputs are $/share; implied EV ($T) = PPS × estimated FD from `data/capitalization.json` (`impliedValuation` in `reference/unitExposure.mjs`). SpaceX live Yahoo with per-SPV carry.
- `/anthropic-ipo-tape` — standing Anthropic IPO tape from the Oct 14 investor day through the listing (`components/InvestorDayTape.jsx`), polls `/api/investor-day` every 15s with `pauseWhenHidden`. Investor-day facts, chart event markers and upcoming milestones live in `data/anthropic-investor-day.json` (validated by `validateInvestorDay`; every record carries `sources[]`); keep "average run-rate" (quarter × 4, computed) and "exit run-rate" distinct and never label anything ARR unless it is an exit run-rate. The σ chart toggles Today (1m) and Since Oct 14 (5m, 15m past 16 days; default through `window.defaultMultiDayUntil`). The disclosure date is `data/disclosure.json` `asOf`; the page warns when it is over 7 days old. All "since" changes are vs 00:00 ET; Kalshi shows bid/ask mids; open-ended cap brackets use $1.125T / $3.125T. Volume rows are per venue with their own windows and are never blended; 24h norms are `(7d − 24h) / 6`. Share card is static (no live numbers, since X caches cards).
- `/private-tape` — Private Tape / DXYZ Shadow NAV lab. Uses returns, not price levels; `lib/privateTape.mjs` owns timestamp windows, no-leakage overnight construction, weighting, correlations, regressions, and CSV helpers.
- `/sftby` — SoftBank Group holdco SOTP (`components/SFTBYSOTPFinder.jsx`, `lib/sftbySotp.mjs`). Dated June NAV bridge from `data/sftby-sotp.json`, shared `/ai` stake/ADR denominator, explicit management sensitivity and post-June funding. ARM / SFTBY / 9984.T / USDJPY quotes from `/api/prices`; June balances stay at reporting FX. `?reference=sftby` freezes quotes, scenario links pin all inputs. `data/SFTBY_METHODOLOGY.md` documents assumptions.
- `/ai` — Pre-IPO Anthropic and OpenAI per $100 (`components/AIPerDollarFinder.jsx`). Live prices from `/api/ai-prices`; wrapper records from `data/` via `lib/loadAiData.mjs`. DXYZ/SKM use `filed-units` with adjustable estimated FD denominators; all quantified legs respond to valuation and dilution. Company and acquisition assumptions live in `data/capitalization.json`. Fund FILED/ESTIMATED in `lib/aiFundBasis.mjs`. Quote chip is market-hours-aware: LIVE/CACHED while RTH is open, CLOSE after the session, STALE only when a quote lags an open market.
